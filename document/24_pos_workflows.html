ขั้นตอนใช้งาน POS แยกตามประเภทร้าน

Phase 28.8.5 · Local · 2026-11-05

ยังไม่ได้ทดสอบกับระบบและอุปกรณ์จริง

ร้านขายของทั่วไปร้านอาหารร้านขายยา

ร้านขายของทั่วไป retail

  1. Cashier / Managerเลือก Terminal และเปิดกะ
  2. Cashier / Managerค้นหา สแกน หรือดึงคำขอ QR ที่พนักงานตรวจรับแล้วเข้าตะกร้า
  3. POS Serverตรวจ catalog ราคา VAT และ quota
  4. Cashier / Managerรับเงินสด ออกใบเสร็จ ตรวจเงินทอน
  5. Cashier / Managerนับยอดจริง ปิดกะ และตรวจรายการรอ ERP

คืนเงินอ้างบิลเดิมโดย Manager ตรวจรับสินค้าตาม workflow ก่อนพิจารณาคืน Stock

ร้านอาหาร restaurant

  1. Cashier / Managerจัดที่นั่งจาก Walk-in หรือจองโต๊ะ แล้วเปิด table session หรือเลือกรับกลับบ้าน
  2. Cashier / Managerบันทึกออเดอร์จากหน้าร้าน หรือรับคำขอ QR ผูกโต๊ะเข้าครัว
  3. POS Serverตรวจเมนูและ quota กันวัตถุดิบและออกเลขคิวตามลำดับรับ
  4. Kitchen / Managerรับออเดอร์ เริ่มเตรียมและตัดวัตถุดิบ แล้วทำสถานะพร้อมเสิร์ฟ
  5. Cashier / Managerเสิร์ฟ เลือกจานที่ชำระ ออกบิล และปิดโต๊ะหลังจัดการครบ

การจองใช้ช่วงโต๊ะ 90 นาที และเผื่อมาสาย 15 นาทีก่อนพนักงานยืนยันไม่มา รายการสั่งเพิ่มได้เลขคิวใหม่ Manager พักหรือข้ามคิวพร้อมเหตุผล

ร้านขายยา pharmacy

  1. พนักงาน POSเลือก Terminal เปิดกะ และเลือกหน่วยขายที่เผยแพร่
  2. Pharmacistดำเนินรายการสินค้าที่กำหนดว่าต้องใช้ role pharmacist
  3. POS Serverตรวจ conversion, lot, expiry, recall และ quota
  4. พนักงาน POSรับเงินสด ออกใบเสร็จ และติดตามสถานะ ERP
  5. Manager ที่เป็นเภสัชกรตรวจของคืนจากบิลเดิม เลือก restock ให้ ERP ตรวจหลักฐาน หรือบันทึก destroy

ประวัติผู้ป่วยใช้ข้อมูลสังเคราะห์และเก็บใน POS Server สาขา Cashier เห็นรหัสและชื่อที่ mask สำหรับเลือกผูกบิล
