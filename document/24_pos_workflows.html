Phase 28.8.1–28.8.5 & UI Redesign (Light / Dark / System & Print #FFFFFF) · Local · 2026-11-06

ยังไม่ได้ทดสอบกับระบบและอุปกรณ์จริง

ติดตั้งสาขาแรก & Configร้านขายของทั่วไปร้านอาหารร้านขายยาDelivery · สมาชิก · Offline

ติดตั้งสาขาแรก /setup และตั้งค่าผู้จัดการ /config

  1. ผู้ดูแลเครื่อง (Local)เตรียม pos/.env, APP_KEY, รัน migrate และตั้ง POS_SETUP_TOKEN
  2. POS Setup Wizard (/setup)กรอกรหัส/ชื่อสาขา เลือก retail / restaurant / pharmacy สร้าง Terminal และ Manager คนแรกแล้วยืนยัน INSTALL
  3. POS Serverสร้างข้อมูลใน Transaction เดียวและล็อก /setup ทันทีเมื่อมีสาขา/Terminal/พนักงานแล้ว
  4. Manager (/config)เพิ่ม Terminal และพนักงานของสาขาตน หรือแก้ชื่อ/ประเภทสาขาก่อนมีข้อมูล provision โดยยืนยันรหัสผ่าน
  5. ERP Admin & Connectorผูก UUID สาขา/Terminal/Staff Authority และเผยแพร่ Catalog, Quota, Tax Profile และโปรโมชัน

ทุกหน้า POS รองรับโหมด Light / Dark / System ที่จำค่าบนอุปกรณ์ และแยกหน้าพิมพ์สลิป 78 มม. / ใบกำกับภาษี / ใบส่งของให้ใช้พื้นขาว (#FFFFFF) เสมอ

ร้านขายของทั่วไป retail

  1. Cashier / Managerเลือก Terminal และเปิดกะ
  2. Cashier / Managerค้นหา สแกน หรือดึงคำขอ QR ที่พนักงานตรวจรับแล้วเข้าตะกร้า พร้อมเลือกสมาชิก/โปรโมชัน
  3. POS Serverตรวจ catalog ราคา VAT สิทธิ์ส่วนลด และ quota
  4. Cashier / Managerรับเงินสด ออกใบเสร็จ/สลิป 78 มม. และตรวจเงินทอน
  5. Cashier / Managerนับยอดจริง ปิดกะ และตรวจรายการรอ ERP

คืนเงินอ้างบิลเดิมโดย Manager ตรวจรับสินค้าตาม workflow ก่อนพิจารณาคืน Stock (Full Refund คืนสิทธิ์คูปองโปรโมชันได้ครั้งเดียว)

ร้านอาหาร restaurant

  1. Cashier / Managerจัดที่นั่งจาก Walk-in (คิวเก่าสุดที่ความจุรองรับ) หรือจองโต๊ะ แล้วเปิด table session หรือเลือกรับกลับบ้าน
  2. Cashier / Managerบันทึกออเดอร์จากหน้าร้าน หรือรับคำขอ QR ผูกโต๊ะเข้าครัว
  3. POS Serverตรวจเมนูและ quota กันวัตถุดิบและออกเลขคิวต่อสาขาตามลำดับรับ (FIFO)
  4. Kitchen / Managerรับออเดอร์ เริ่มเตรียมและตัดวัตถุดิบ แล้วทำสถานะพร้อมเสิร์ฟ
  5. Cashier / Managerเสิร์ฟ เลือกจานที่ชำระ (แยกบิลตามรายการได้) ออกบิล และปิดโต๊ะหลังจัดการครบ

การจองใช้ช่วงโต๊ะ 90 นาที และเผื่อมาสาย 15 นาทีก่อนพนักงานยืนยันไม่มา รายการสั่งเพิ่มได้เลขคิวใหม่ Manager พักหรือข้ามคิวพร้อมเหตุผลลง Audit

ร้านขายยา pharmacy

  1. พนักงาน POSเลือก Terminal เปิดกะ เลือกหน่วยขายที่เผยแพร่ และดูรหัสล็อต/วันหมดอายุ (FEFO) ข้างตะกร้า
  2. Pharmacistดำเนินรายการสินค้าที่กำหนดว่าต้องใช้ role pharmacist และตรวจประวัติผู้ป่วยสังเคราะห์ (ถ้าผูกบิล)
  3. POS Serverตรวจ conversion, lot, expiry, recall และ quota
  4. พนักงาน POSรับเงินสด ออกใบเสร็จ และติดตามสถานะ ERP
  5. Manager ที่เป็นเภสัชกรตรวจของคืนจากบิลเดิม เลือก restock ให้ ERP ตรวจหลักฐาน หรือบันทึก destroy

ประวัติผู้ป่วย (/patients) ใช้ข้อมูลสังเคราะห์เข้ารหัสเฉพาะสาขา ไม่ส่งไป ERP หรือ Offline Queue; Cashier เห็นเฉพาะรหัสและชื่อที่ mask สำหรับเลือกผูกบิล

ส่วนขยายร่วม Phase 28.8.1–28.8.3 (Delivery · สมาชิก · Offline PWA)

  1. Delivery (/deliveries)รับงานจัดส่ง Retail/Restaurant แบบ Prepaid หรือ COD (ปิดสำหรับ Pharmacy 100%)
  2. COD Custodyบันทึกเก็บเงินปลายทาง (collect) และส่งมอบเงินเข้ากะเปิดของ Manager (remit) แยกจากสถานะส่งของ
  3. Membership (/membership)ส่งคำขอสมัครเข้ารหัส Hybrid (AES-256-GCM + RSA-OAEP) รอ ERP อนุมัติ และใช้ส่วนลดก่อน VAT
  4. Offline Permit (/offline/app)ขอ Permit จองโควตาสต็อกและสล็อตบิลขณะออนไลน์ พร้อมตั้งรหัสปลดล็อกคิวเข้ารหัส PBKDF2 600k
  5. Offline Review & Syncเมื่อกลับมาออนไลน์ Manager ตรวจรับเงินสดเข้ากะปัจจุบันก่อนสร้างบิลและส่ง Signed Event ไป ERP
